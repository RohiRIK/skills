# Exploration and motion

## Prerequisites

A concrete need to vary inputs or observe motion. Read the delivery workflow. Existing approval rules remain in force.

## Steps

1. For what-if exploration, use a small local HTML calculator, comparator, or simulator. No tracking, sensitive-input persistence, remote requests, or embedded credentials. Escape input or use textContent rather than unsafe HTML insertion.
2. Label units, defaults, assumptions, limits, and hypothetical versus measured values. Verify normal, edge, and invalid cases using independent tool-executed calculations. Provide validation feedback, keyboard access, and readable fallback.
3. For temporal understanding, load an available animation/video production skill. Render and inspect playable output, visible text, audio if present, and captions/transcript. A video may be the main deliverable without an HTML wrapper.
4. Prefer free/local production where feasible. Paid narration, external uploads, or sending sensitive material require explicit approval. Do not silently consume paid APIs or install large dependencies for decoration.
5. Execute the verification workflow. If production is blocked, report it precisely and deliver the best verified alternative with its limitations.

## Exit Criteria

The chosen interaction or video serves a concrete understanding need, results are tested, actual files are delivered, and no unauthorized external effects occur.
