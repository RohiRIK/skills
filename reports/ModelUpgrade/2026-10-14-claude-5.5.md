# Model upgrade report — claude-5.5 — 2026-10-14

**Target:** `claude-5.5` (Claude Opus 5.5 as default, Fable 5.1, Sonnet 5.5, Haiku 5.5), the head of `skills/ModelUpgrade/Generations.md`.
**Scope:** all 41 skills under `skills/` (40 existing plus ModelUpgrade itself), their workflows and context files. Host overlaps were checked against Claude Code's built-in skills as listed in this session.
**Method:** `ModelUpgrade.ts scan` for leads (58 hits across 14 skills), a read of every `SKILL.md`, and `Rubric.md` for the verdicts. This is the first run, so no skill had a previous `tuned-for` stamp.

## Summary

The library is in good shape for the new generation. 35 of 41 skills are stamped `claude-5.5`; 8 of them needed rewording or fact fixes first. The fixes were mostly stale facts rather than dated wording. The main findings:

1. **The prompting standard was written for Claude 4.x.** `Prompting/vendors/Claude.md` is what every skill is authored against. It still gave advice for thinking-off models, had no effort guidance, and had no notes on de-prescription, formatting, narration, or reasoning-extraction refusals. It now targets the 5.5 generation, and per-generation history moved to the ledger. This change has the most leverage, since every future skill goes through `Prompting`.
2. **Skills referred to commands and tools that no longer exist.** These were `/plan`, `/test`, `/commit-push-pr`, `/build-fix`, `/cse`, a "StoryExplanation" skill, two private MCP tool names in `Spec`, and a wrong tier claim in `Research`. They break the library's own host-portability rule (`rules/system.md` §7), and on current models they cause an instruction to be followed literally against a tool that isn't there. All are fixed.
3. **Six skills need a decision or an A/B test before they count as tuned.** They are listed below and remain unstamped, so `ModelUpgrade.ts baseline` keeps showing them until they're done.

Counts: keep 27 · reprompt (applied) 8 · replan 3 · retire candidates 2 · keep pending an A/B 1.

## Decisions for the owner

| Skill | Recommendation | Why |

| **Simplify** | Retire it, or rename it to `DiffCleanup` and narrow the description | Claude Code now ships a built-in `simplify` skill with the same name and job, so routing between them is a coin flip. It also delegates to a `code-simplifier` agent this repo doesn't ship. |
| **StrategicCompact** | Retire it and fold its two gotchas into `ContextBudget` | Current hosts compact automatically, and current models have 1M-token windows and track their remaining context. | **CreateCLI** | Replan it as the shared base (context files plus a router) for `CreateCLI-Agent` and `CreateCLI-Human` | Three skills trigger on "create a CLI". The siblings already reuse its context files, and both siblings are well over the 50-line canon (146 and 99 lines). |
