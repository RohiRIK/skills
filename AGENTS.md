# Skills — personal Agent Skills library

Personal library of reusable Agent Skills. Each subfolder is one skill.

## Your role

Help add and maintain skills correctly. Apply the rules below on every skill-creation or review task.

## Rules

- Each skill is a folder at the repo root containing a `SKILL.md` with `name` + `description` frontmatter.
- Folder names are TitleCase (mirror `~/.claude/skills`); the `name:` field drives activation.
- Every skill needs a row in [README.md](README.md) under "Skills in this repo".

## Where to go

- **Repo layout + conventions** → [CLAUDE.md](CLAUDE.md)
- **Install a skill into an AI tool** → [INSTALL-AI.md](INSTALL-AI.md)
